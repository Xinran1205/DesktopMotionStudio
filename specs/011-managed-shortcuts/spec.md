# Feature Specification: F10 受管理快捷方式

**Feature Branch** `codex/f10-managed-shortcuts`

**Created** 2026-11-03 · **Updated** 2026-11-06 · **Status** Complete

**Input** PRD V1.0, TDD V1.0 §9, F02/F04/F07/F08/F09 contracts

## User Scenarios & Testing

### User Story 1 — 创建桌面入口并独立启动 (P1)

用户为已启用且可用的绑定创建桌面入口。关闭 Studio 后使用入口，目标应用按现有实例与启动规则打开。

**Independent Test** 在隔离配置和桌面目录保存测试应用与有效绑定，创建入口，关闭 Studio，再激活入口。

1. **AC-01** 创建成功后桌面存在一个经回读验证的入口。重复点击和同时发起的 Studio 请求至多保留一个已登记入口。
2. **AC-02** Studio 已退出时激活入口，Launcher 读取最新绑定并沿现有生命周期启动或激活目标。更换作品后，同一入口使用新作品。
3. **AC-03** 动效关闭、作品不可用或渲染失败时，可用目标仍经原生流程打开。绑定或目标缺失、参数不合法、配置未知版本时给出明确失败。

### User Story 2 — 安全修复和移除 (P1)

用户能够在主页确认入口状态，修复丢失或过期入口，或者移除仍验证为本软件所有的入口。

**Independent Test** 在隔离目录放入同名入口、移动或改写已登记入口，再分别读取状态、修复和移除。

1. **AC-04** 同名其他文件、用户改写文件、链接或同内容替换物保留原样。冲突结果可见。产品只管理已登记位置，重命名或移动后的入口保持原样。
2. **AC-05** 对登记但缺失的入口，修复可在当前受支持桌面重建。对验证通过且指向旧 Launcher 的入口，显式修复能更新目标。
3. **AC-06** 移除只针对当前经验证的入口，保留应用、绑定和第三方快捷方式。停用动效与移除入口是独立动作。
4. **AC-07** 目录重定向、重解析点、权限不足、文件占用或路径更换时，显示不可用、冲突或失败。仅在验证成功时报告已创建或已移除。

### User Story 3 — 部分失败后恢复 (P2)

用户重新打开 Studio 后可检查此前被中断的创建或修复，并选择重试。

**Independent Test** 在登记前、登记后发布前、发布后回读前注入失败或退出，再用新进程读取状态并重试。

1. **AC-08** 登记失败不产生可点击入口。已发布但未确认的入口可以凭持久记录重新验证。未发布的操作可再次显式修复，同时出现的文件保留原样。
2. **AC-09** 所有权数据损坏、版本未知或锁超时，操作失败且保留文件与登记原始字节。首次安装和 F09 配置均可正常读取。

### Edge Cases

- 不合法或过长应用名称、同名应用、重复点击、Windows 大小写等价路径、桌面重定向、符号链接/联接、硬链接、同内容复制和锁竞争。
- Launcher 缺失、应用已移除、绑定已禁用、作品已替换、非预期 CLI 参数。
- 第三方同时写入、删除或替换文件。变更操作依据持有的文件身份并采用无覆盖发布。

## Requirements

### Functional Requirements

- **FR-001** 仅用户对现有可用绑定显式发起创建或修复，才可发布入口。入口位于当前用户的受支持本地桌面。
- **FR-002** 入口指向随附的独立 Launcher，仅携带内部绑定 ID。目标路径、参数和启动策略从已验证的当前配置读取。优先使用可验证的本地目标图标，其余使用产品默认图标。
- **FR-003** Launcher 使用既有目标验证、实例协调和 MotionHost 生命周期。禁用或不可用动效降级原生启动，目标验证失败给出错误。一次调用最多提交一次目标调度。
- **FR-004** 记录绑定、规范化位置、原始文件身份和内容验证信息。变更前验证当前位置、身份和内容。用户移动、修改或复制的入口不取得所有权。同名冲突不覆盖。
- **FR-005** 主页提供创建、修复、移除和健康状态。状态至少区分未创建、有效、缺失、待修复、冲突和不可用。键盘可完成各动作。移除入口保留绑定与应用资料。
- **FR-006** 创建和修复在入口可用前持久化恢复所需信息。失败、并发、重试和中断产生可诊断状态。未知版本、损坏和锁失败拒绝写入。现有 profile schema2 和备份保持兼容。
- **FR-007** 使用普通用户权限，离线运行。限定在已验证的当前用户桌面和用户私有登记目录。原生应用和第三方入口保持原样。
- **FR-008** 发布构建包含独立 Launcher 及依赖。开发发布路径由 F10 验证，稳定安装路径由 F12 交付。

### Business Rules, Inputs & Outputs

- **Input** 当前绑定 ID、用户明确的创建/修复/移除意图、当前用户桌面能力及已提交配置。
- **Output** 单个桌面快捷方式、独立版本化所有权记录及结构化状态。创建和修复要求实时可用的目标和作品。移除只需验证所有权。
- **Rule** 移动后的入口由用户管理。显式重建只管理新的登记位置。删除已保存应用可以使旧入口失效。无关联入口的清理仍遵循所有权校验。
- **Rule** 支持可确认文件身份和原子操作的本地桌面。无法安全访问的网络或重解析路径显示不可用。

### Key Entities

- **Managed entry** 绑定 ID、桌面路径、文件身份、内容指纹和 Launcher 位置。
- **Ownership receipt** 独立版本化的登记记录，用于回读、故障恢复和验证变更。
- **Launch request** 内部绑定 ID 及从已提交配置解析出的目标、可选作品和结果。

## Success Criteria

- **SC-001** 同名冲突、内容修改、身份变化、硬链接、重解析与并发测试中，第三方文件零覆盖、零误删除。
- **SC-002** 真实 Windows 发布目录中，Studio 退出后可由实际快捷方式调用 Launcher 并启动测试目标。覆盖真实作品播放/交接和原生降级。
- **SC-003** 进程中断、I/O 和锁失败具备自动化证据。测试比较原文件、配置与备份字节。
- **SC-004** F02/F04/F07/F08/F09 回归通过，F10 主页键盘流程和桌面限制有真实验证记录。

## Assumptions

- V1 面向 Windows 11 x64。F10 依赖已交付的 F02、F04、F05、F06、F07、F08、F09。
- 高风险能力先用工作站隔离文件验证。性能先记录真机基线。

## Clarifications

### Session 2026-11-06

- 创建入口需要已有启用且可用的绑定。之后停用动效仍可通过该入口原生启动目标。
- 既有绑定 ID 继续有效，包括 F02 迁移的非 GUID ID。静音设置用于音频，现有无声作品仍可播放。
- 同名冲突保留现有文件并报告冲突。移动入口后只允许在原登记路径或当前受支持桌面显式重建。
- 已登记入口的 Launcher 过期时可以显式修复。用户改写过的入口由用户自行处理。
- 所有权数据使用独立版本，已有 F09 配置和备份无需迁移。无需用户决策的技术限制和测试环境选型记录在 Plan。
