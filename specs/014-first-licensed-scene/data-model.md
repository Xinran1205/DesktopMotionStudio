# F13 数据与状态

| 对象 | 身份与约束 |
| --- | --- |
| 「零界」内置作品 | 稳定 ID `zero-boundary`，与 Studio Pulse 分立。清单、展示、播放的作品 ID 和版本须一致。封面、来源记录和画面随包，路径继续由内置资源校验。 |
| 受控播放定义 | `tech-frame` v1 提案。约 2000 毫秒的分镜数据复用 schema 1 的有界时间轴和快照。现有 `vector-orbit` v1 继续可读；未知版本安全拒绝。 |
| 画幅 | 作品推荐值在原有清单内。临时比较请求在测试会话内采用居中或全屏，不写回用户配置。 |
| 演出状态 | 准备、可见、收尾、退出。退出分类为就绪交接、正常播完、跳过、失败或 watchdog 超时。应用启动结果独立，原先的绑定与设置不迁移。 |
