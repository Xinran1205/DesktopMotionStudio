# Feature Specification — F13「零界」与完整启动演出

- **Feature Branch**　`codex/next-experience-polish`
- **Created**　2026-11-03 · **Updated**　2026-11-07
- **Status**　0.2.0 · 计划实施
- **Input**　PRD V1.0 §4–6、用户已确认的纯科技方向、F15 已验收的启动流程。

## User Scenarios & Testing

### User Story 1 — 先欣赏完整作品（P1）

我想在作品库看到「零界」的真实封面，再预览完整开场，判断是否适合我的应用。

**独立测试**　在已有 Studio 界面用一个测试配置打开作品库，从预览开始看完整三段。重复预览，分别验证键盘和指针退出。

1. 选择「零界」并预览时，可看见石墨黑与冰蓝组成的点亮、对齐、收束三个阶段。Studio 标记预览，舞台常态下只有作品，且没有应用进程被启动。
2. 播放中按 Esc，或通过指针移动、键盘导航找到退出控件并操作，动效退出。结束后能回到原来的预览入口。
3. 在本机小样中切换居中与全屏时，两版保留主要图形的比例和取景，均可退出。开启 Windows 减少动态效果后，预览使用静态或极简画面。

### User Story 2 — 作品自然交给真实应用（P1）

我想为常用应用绑定同一套作品，并从「测试启动」或自己的受管入口看到顺畅的开场。

**独立测试**　分别为两个不同测试应用绑定「零界」。用试启动与受管入口覆盖首次启动、窗口迟到及已有窗口的情况。

1. 冷启动时，真实应用按原有流程启动。窗口就绪时触发短交接，应用直接可用。已经打开的应用沿用窗口复用行为。
2. 窗口迟到时，作品按自身时长柔和退场，随后应用照常打开。用户按 Esc 时也保留本次启动。两个入口均无额外分派。
3. 作品不可用或渲染异常时，画面及时退出，原生启动继续。Studio 显示可理解的结果，原应用数据、绑定和入口保持有效。

### Edge Cases

- 窗口早于第一帧就绪，交接与 Esc 同时发生，目标始终未出现，渲染器异常退出或挂起。
- 作品版本或素材不可用，Studio Pulse 旧绑定仍存在，目标已运行，两个请求快速到达。
- 小工作区、高 DPI、非标准宽高比、多显示器，以及 Windows 动画关闭。

## Requirements

### Functional Requirements

- **FR-001**　新增独立原创内置作品「零界」。交付独立封面和说明、点亮 → 对齐 → 收束的分镜、可追溯的素材来源。完整预览的创作目标约 2 秒。
- **FR-002**　作品库提供无目标应用的完整预览。预览和真实启动的同一时间点使用同一视觉编排。模拟交接的说明在 Studio 界面可见。
- **FR-003**　「零界」的预览和真实启动常态画面没有说明、演示标签、诊断文字或常驻底栏。Esc 可退出。指针活动和键盘导航均可发现一个有辅助名称与焦点反馈的退出控件。
- **FR-004**　交付可在本机对比的居中大画幅、单屏全屏小样，保持图形比例、重点构图与安全边距。默认采用作品推荐模式，当前推荐居中。对比结果记入验收，用户尺寸偏好单独排期。
- **FR-005**　以目标窗口实际就绪触发短交接，允许早到时提前结束或略过画面。晚到时作品到点退场，应用继续正常启动。目标应用保持自己的窗口位置和大小。真实目标由绑定决定，热启动沿用原有复用流程。
- **FR-006**　资源无效、渲染器异常、用户跳过或系统减少动态效果时，使用相应的安全退场。诊断区分正常到点退场、用户退出和真实渲染故障。
- **FR-007**　现有 Studio Pulse 绑定、配置和受管入口保留。「零界」可在普通用户权限、无网络下预览和播放。渲染隔离与已验证的入口归属约束继续适用。

### Key Entities

- **内置作品**　有稳定身份、版本、原创建议构图、封面、演出和素材来源。
- **启动演出**　由绑定与入口触发。呈现作品并以就绪、到点、跳过或故障结束。

### Business Rules, Inputs & Outputs

- **输入**　作品库选择或已有绑定、受支持的目标应用、Windows 动态效果偏好、目标窗口就绪事件。
- **输出**　完整预览或真实启动画面、退出原因与应用启动结果。预览只模拟交接。
- **规则**　应用启动独立于演出。短分镜和画幅只约束作品。任何新持久化格式、任意场景代码、屏幕内容保存或目标窗口强制移动都在本阶段范围之外。

## Success Criteria

### Measurable Outcomes

- **SC-001**　本机保存居中和全屏各一份可对比记录。两版完整预览均看到三个分镜，常态画面无说明，构图无拉伸或关键内容裁切。常规完整播放在首帧可见后 2.5 秒内退场，包括正常收尾。
- **SC-002**　至少两个不同测试应用成功冷启动，合计覆盖首页测试启动与受管入口。可见演出收到就绪通知后 300 毫秒内关闭。晚到用例在 2.5 秒内无覆盖，真实应用随后可用。已有窗口仅复用。
- **SC-003**　预览与真实播放均能用 Esc 或可发现的按钮退出，前者不启动目标，后者不中断目标。素材错误、渲染故障和系统减少动态均有验证，且不会留下可见遮挡或孤立的动效进程。
- **SC-004**　用 0.15.0 格式的测试配置和原有 Studio Pulse 绑定通过新版预览、真实启动复测。新作品随包素材逐项有来源与分发记录。

## Assumptions

- 依赖 F03 作品库、F05/F06 启动和交接、F07 绑定、F09 预览、F10 受管入口及 F15 测试启动。F16 首页改版可稍后实施。
- 第一套选择原创、静音的程序化作品。外部项目仅作视觉参考。增强式真窗口融合留作以后独立的可行性研究，本阶段的验收以自然且可靠的交接为准。
- 隐藏常态说明适用于「零界」。已有作品可沿用各自的呈现。
