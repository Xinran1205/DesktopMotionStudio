# F13 代码复核与规格收敛

2026-11-08 对小样、产品预览、窗口生命周期、测试夹具和发布资源分别做了独立于实现的复核。

| 范围 | 结论和可复查结果 |
| --- | --- |
| FR-001、FR-002、FR-004 · SC-001 | 新运行时只在版本白名单内可用，预览与启动共用同一构图。原型的两种画幅留证，作品默认居中。封面由同一画面导出，随包有来源记录。 |
| FR-003、FR-006 · SC-003 | 画面正文无常驻说明。Studio 显示预览提示，键盘和指针退出通过。静态路径用真实系统设置验证。正常退场、跳过、协议错误、失败与超时分类有各自证据。 |
| FR-005 · SC-002 | 目标分派独立于宿主完成。父端在 Started 前可撤销演出所有权，终态接收与更新受同一把锁保护。完成信号与交接或停止请求交错时不被误记。两个真实测试应用经不同入口运行，目标窗口几何由应用持有。 |
| FR-007 · SC-004 | 旧绑定、入口归属和持久化协议保持。旧作品从新版目录预览和启动通过。未引入窗口捕获、可执行场景脚本、新依赖或外部媒体。 |

复核期间发现并修正了 IPC 读取器仍拒绝新运行时、以及有限演出终态与停止请求交错时可能被误判的问题。当前 F13 已完成逐条收敛。实际数据与复现范围见 [evidence.md](evidence.md)。升级包和图标在 F16 验收。
