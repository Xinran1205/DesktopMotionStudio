# F13 播放与交接合同

| 入口或事件 | 可观察结果 |
| --- | --- |
| 作品库／首页预览 | 播放同一作品并可完整看到收束。说明在 Studio 的状态区。预览不携带目标信息，没有分派和真实交接权限。 |
| 冷启动 | 真实应用按现有管线分派一次。可见演出收到窗口就绪即交接。目标早于宿主显示时，允许直接呈现真实应用；验证无迟到遮挡。 |
| 目标迟到 | 演出在作品预算内收尾并退出。目标继续启动，宿主结束不会截断目标等待或触发第二次启动。 |
| Esc 或退出控件 | 在普通播放和淡出中均可退出。控件默认让出作品画面，指针活动或 Tab 导航可发现并操作，键盘焦点可见。预览退出返回触发处。 |
| 渲染／资源失败 | 启动继续，隔离宿主按现有守护关闭。诊断区分原因。Windows 减少动态效果下显示静态或极简画面并快速退场。 |

IPC3 保留 Ready、Start、Started 和 Handoff 的角色边界。只允许已通过校验并支持有限演出的 Launch 运行时从可见、交接态，或与关闭请求交错时报告自然 `Completed`。Preview 继续只接受模拟收尾与自己的终态。若正常完成与 Handoff、Skip 或失败竞争，以第一个合法终态收敛，不覆盖已经确定的结果，不把正常完成报告成故障或超时。旧协议或未知运行时按照原有版本检查失败并继续原生启动。IPC 不传目标进程、窗口句柄、屏幕内容或应用参数。
