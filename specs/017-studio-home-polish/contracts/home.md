# F16 首页交互合同

| 状态 | 首页主行为 |
| --- | --- |
| 无应用 | 突出「添加应用」。无搜索匹配时说明筛选状态并能清除。 |
| 已选、未绑定 | 突出「选择动效」。通过现有选择器保存后显示封面和作品名。 |
| 有绑定且目标可用 | 突出「测试启动」。预览与替换可达。动效停用或作品不可用时说明状态，并保留现有原生试启动能力。 |
| 入口失效或配置不可读 | 显示状态并提供适用的重新确认或刷新操作。禁止绕开原有写入、启动和归属约束。 |
| 试启动或预览进行中 | 反馈当前操作，防止重复分派。切换应用不会把旧状态画到新应用。预览可结束且只模拟交接。 |

默认主操作有文字及可见焦点。保留既有快捷键、AutomationId 与辅助名称的语义。入口维护、设置和诊断使用明确名称。布局可以压缩或滚动。受管桌面入口沿用自己的目标图标规则。
