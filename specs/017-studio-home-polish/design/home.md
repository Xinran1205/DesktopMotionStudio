# 首页定稿依据

以现有 900×560 DIP 最小窗口作为第一屏。顶部用短标题和小型标志，右上保留「动效作品库」「设置」「本地诊断」。正文左侧约 260 DIP 用于搜索和选择应用，右侧留给选中应用、真实作品封面与下一步。大窗口把新增空间交给作品区。

| 左栏 | 右栏首屏 | 最醒目的操作 |
| --- | --- | --- |
| 空列表、添加入口 | 简短说明「先添加一个要使用动效的应用」，右侧可保留安静的占位 | 添加应用 |
| 已选应用，未绑定 | 应用名、作品占位和选择提示 | 选择动效 |
| 已绑定，目标可用 | 应用名、封面、作品名称和状态。试启动、预览、替换同一行，反馈紧邻。 | 测试启动 |
| 筛选无结果 | 清除搜索可恢复列表和原操作 | 清除搜索 |
| 入口失效 | 保留应用和绑定信息，将重新确认入口放在状态附近 | 确认入口 |

右侧第一屏之后依次放受管桌面入口和应用设置。停用、修复和移除都有文字和焦点状态。键盘焦点从导航到应用列表，再到当前作品和维护。已有助记键保留。长名称在详情可换行，在列表保留完整的辅助名称。布局在高缩放时允许滚动。

视觉采用低饱和的系统主题底色、分区线、36 DIP 操作高度、清晰焦点和少量圆角。作品封面提供画面色彩，主要按钮使用系统强调色以兼容浅色、深色和高对比度。

产品标志由深色底上的两扇错位窗口组成，前框使用明亮冰蓝，后框用较暗蓝色。以 32×32 网格作为源尺寸，16 像素时仍保留两层轮廓。 [图标源稿](icon.xaml)
