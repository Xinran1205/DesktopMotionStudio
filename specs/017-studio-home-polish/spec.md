# Feature Specification — F16 Studio 首页与产品图标

- **Feature Branch**　`codex/next-experience-polish`
- **Created**　2026-11-07
- **Status**　0.1.0 · 计划实施
- **Input**　PRD V1.0 §2–4、用户确认的首页视觉打磨、F13「零界」、F15 测试启动。

## User Scenarios & Testing

### User Story 1 — 在首页完成第一次试启动（P1）

我希望一眼知道当前选中哪个应用、绑定哪套作品，以及接下来该点哪里。

**独立测试**　从空的隔离配置开始，依次添加应用、选择作品、预览、测试启动。使用一个已有绑定重复测试启动，然后按需创建入口。

1. 空首页突出添加应用。选中未绑定应用后，主操作变为选择动效。绑定有效后，主操作变为测试启动，旁边可预览和替换。
2. 「预览」只播放作品。「测试启动」打开当前应用并反馈结果。状态属于发起该操作的应用，切换选择后不会被旧结果误导。
3. 一轮试启动完成后，用户可以自己选择创建桌面入口。原入口管理功能仍能找到，试启动自身不创建入口。

### User Story 2 — 看清状态并处理例外（P1）

我希望用键盘和适合自己的主题操作。遇到停用、入口失效或作品不可用，也能看懂原因并恢复。

**独立测试**　用键盘完成一次已绑定应用的试启动，走一遍入口恢复或作品替换，在不同主题和桌面缩放下检查首页。

1. 浅色、深色、跟随系统与高对比度下，主次按钮、焦点、禁用状态与错误信息均清楚。缩放后可以通过布局或滚动触达所有主操作。
2. 入口失效、配置加载异常、作品不可用、没有搜索结果和试启动进行中各有对应状态。恢复、改名、移除、设置和诊断可达。

### User Story 3 — 从 Windows 认出 Studio（P2）

我希望在任务栏、开始菜单和安装入口中看到同一个辨识度足够的产品图标。

**独立测试**　在 Windows 本机用候选包安装或升级后核对图标与已有入口。检查图标在 16 像素下仍能辨认。

1. Studio 的窗口、任务栏、开始菜单、可执行文件、Setup 和「已安装的应用」呈现一致的产品标识。
2. 旧绑定、入口指向和归属在升级后仍有效。第三方应用的入口图标维持既有的目标应用图标规则。

### Edge Cases

- 空列表、无搜索结果、封面缺失、绑定停用、入口失效、状态只读、启动进行中切换应用。
- 长中文名称或路径、窄窗口、高 DPI、高对比度主题。系统缓存保留升级前图标。

## Requirements

### Functional Requirements

- **FR-001**　首页围绕「选应用 → 选动效 → 预览 / 测试启动 → 按需创建入口」组织。左侧应用列表，右侧作品封面、绑定状态和主操作。空、未绑定、已绑定可启动的默认主操作分别为「添加应用」「选择动效」「测试启动」。
- **FR-002**　原创视觉以清楚的按钮层级、字体、留白和焦点为核心。保留作品自身色彩，提供封面缺失时的可读占位。维护、停用和入口操作按当前状态在有名称的位置呈现。
- **FR-003**　保留既有预览、绑定、测试启动和入口行为、键盘快捷键及错误反馈。试启动有进行中状态，切换应用时结果仍对应发起项。页面可访问性保留明确控件名称和可见焦点。
- **FR-004**　首页在浅色、深色、跟随系统和 Windows 高对比度下可用。在现有支持的最小窗口和 100%、125%、150% 缩放下，主要操作保持可触达，文字可换行或有完整读法。
- **FR-005**　从双层窗口轮廓提炼独立产品图标。在 16 像素下辨识轮廓，统一 Studio 窗口、任务栏、开始菜单、产品可执行入口、Setup 及已安装应用列表。
- **FR-006**　升级保留应用、作品绑定、设置与受管入口的持久化状态。界面重排保持同一权限与文件归属边界。

### Key Entities

- **首页应用状态**　当前应用、入口状态、绑定作品、预览状态、试启动及入口操作结果。
- **产品图标**　可追溯的原始设计与由其导出的一组 Windows 图标资源。

### Business Rules, Inputs & Outputs

- **输入**　现有应用和绑定状态、作品封面、用户操作、Windows 主题和缩放、安装或升级。
- **输出**　下一步明确的首页、同一套产品标识，以及现有真实应用与快捷方式操作结果。
- **规则**　作品库只做支持首页闭环所需的改动。设置与诊断继续可达，详细窗口的全面改版另行排期。

## Success Criteria

### Measurable Outcomes

- **SC-001**　从空首页只用首页和现有选择窗口完成添加、绑定、预览及一次真实试启动。选中已有效绑定的应用后，可通过一个按钮或 Alt+T 发起试启动，无须先创建入口。
- **SC-002**　用键盘完成主流程并检查停用、入口失效、作品不可用和正在启动等状态。在本机覆盖规定主题与 100%、125%、150% 缩放，主要操作均可触达，无按钮文字重叠。
- **SC-003**　用实际候选包核对 FR-005 所列 Windows 入口，保存 16 像素图标和任务栏截图。覆盖一次 0.15.0 升级，保留已存在的绑定和入口，并从原有受管入口成功启动一次。

## Assumptions

- 依赖 F08–F12、F15 的现有行为。F13 先交付真实封面、作品状态与预览回路。F16 直接使用这些交付物。
- 深色作为视觉设计起稿，发布时保留用户已有主题偏好。既有应用的桌面入口继续使用现有目标图标规则。
