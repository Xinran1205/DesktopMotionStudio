# F24 — AI motion creation guide

A user with only a concept can open the guide from MP4 import. It returns a copyable brief with three beats, generation prompts, composition guidance, measured duration, export parameters and a local import checklist. The same rules can be packaged as an optional authoring Skill.

Use the actual supported media profile. The guide works with the user's chosen external AI or editor. It covers reference rights and avoids inventing a direct video-generation capability inside Studio.

Accept when an original test brief produces a usable exported MP4 that passes the Studio importer and runs through preview and binding. Depends on F22 and the F23 creative evidence.
