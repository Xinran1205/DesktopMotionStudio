# F24 — AI motion creation guide

A user with only a concept can open the guide next to MP4 import. The guide takes a short concept, a style and a choice of 5, 6, 8 or 10 seconds. It returns a copyable brief with timed beats, generation prompts, composition guidance, export parameters and a local import checklist.

Use the actual supported media profile. The guide works with the user's chosen external AI or editor. It covers reference rights, playback safe framing and the Studio import checks. Keep the concept local to the window until the user copies the result. Localize the controls and brief in the selected Studio language.

Accept when a user can fill and copy a brief in both languages, and an authored sample using the brief's export rules passes the Studio importer, preview and binding. Reuse Orbit Ignition as the six-second reproducible example. Depends on F22 and F23.
