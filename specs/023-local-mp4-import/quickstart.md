# F22 acceptance path

Use an isolated Windows profile directory and the generated AAC and silent files from the [F21 quickstart](../022-mp4-playback/quickstart.md). Start with one real import, then run the fault cases applicable to the files changed.

1. Import the AAC file through My motions. Check the default duration, complete display and sound off. Change all three options and preview before saving. Escape should return to the editor.
2. Save, bind to two isolated target apps and move the original video. Restart Studio. Test launch and a real desktop shortcut should still play the copy and open their targets after playback.
3. Rename and edit the work, then verify both old bindings. Remove it and verify the same links open their targets without playback.
4. Repeat the relevant operation with a malformed file, read-only destination, unsafe path, interrupted copy or pending playback. Check for visible partial work and compare the existing profile, media and shortcut bytes.
5. Switch language and verify the import prompts and an error. The imported name should keep its original text.
