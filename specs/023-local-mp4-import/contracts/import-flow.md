# F22 Studio interaction

1. **My motions → Import MP4.** Choose a local file. Show a cancellable validation state, then present the name, duration, fit and sound choices. Display actionable failures beside the current operation.
2. **Preview.** Show the exact draft settings. Escape stops only the preview. Closing or discarding the editor cancels its pending work and leaves the catalog unchanged.
3. **Save.** Stop the draft preview and publish the inspected work once. If cancellation arrives after publication, report the saved work. A completed import is playable after moving the source and restarting Studio. The work can be selected by the existing binding UI.
4. **Edit and remove.** Edit name and settings as one operation. Preserve the work ID. Removal explains the effect on bindings and requires the user to confirm in Studio. If removal cannot complete, keep the work visible and show the reason. A committed removal leaves existing links usable for ordinary app launch.

The controls and errors appear in English or Chinese according to Studio's preference. Names entered by users retain their original text.
