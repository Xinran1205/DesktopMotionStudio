# Feature Specification — F15 测试启动

**Status** Planned · **Date** 2026-11-07

**Input** PRD V1.0 §2.2、§3 F06、§4.1，TDD V1.0「测试启动」。

## 用户场景

用户为已保存应用选好动效，在「我的应用」直接点击「测试启动」。Studio 打开真实目标并执行当前配置的转场。用户可以在决定创建受管桌面入口之前验证效果。

1. **AC-01** 已保存、已绑定且目标可用时，从首页使用键盘或鼠标触发一次测试启动。行为与使用该绑定的受管入口一致。
2. **AC-02** 目标已有可确认的运行窗口时复用该窗口，无重复启动或演出。动画停用或渲染器不可用时按同一启动链路降级。
3. **AC-03** 无绑定、目标失效、配置不可读取或启动组件缺失时，Studio 显示可执行的修复或重试提示。
4. **AC-04** 启动与失败均不写入配置、备份、桌面入口或所有权凭证。启动诊断沿用现有脱敏合同。

## 功能需求和业务规则

- **FR-001** 首页为已保存的有效绑定提供明确、键盘可访问的测试启动操作，显示提交中和请求结果。
- **FR-002** 测试使用当前绑定、目标和动效启用状态。用户从旧界面触发后，以 Launcher 读取的最新有效配置为准。
- **FR-003** 复用受管启动的目标验证、实例协调、渲染降级和日志。每个已接受请求最多调度一次目标。
- **FR-004** 重复触发在同一个首页请求期间合并。切换选择时，上一请求的完成状态不得覆盖当前应用的提示。
- **FR-005** 关闭 Studio 不终止已调度的目标应用。成功、失败、超时和组件缺失的提示可区分。

**输入** 已保存应用、绑定标识和用户操作。

**输出** 一次实际目标启动或已有窗口激活，以及 Studio 的本次请求状态。

**边界** 配置并发变更、失效或未知的绑定、动画停用、重复操作、切换选中项、Studio 关闭、安装中占用、渲染异常。

**依赖** F05 实例协调、F06 渲染降级、F09 首页与绑定、F10 受管 Launcher、F11 诊断。按当前交付流程，实施前完成 F12。

## 验收与测试

- **SC-001** 在未创建受管入口的隔离测试配置中，通过首页实际启动一个测试目标并观察转场。随后创建入口，验证两条路径的调度和诊断一致。
- **SC-002** 覆盖已运行、动画停用、渲染故障、失效绑定、重复点击、切换和关闭 Studio。每个受理请求最多启动一次目标。
- **SC-003** 测试前后比对配置和备份哈希，以及桌面与凭证目录。只有符合 F11 的诊断记录可以新增。
