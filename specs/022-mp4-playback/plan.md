# Plan — F21 production MP4 playback

Start from the F20 Media Engine frame-transfer evidence. Reuse the decoder and stage behavior behind a separate video session. Keep the current code-work manifests, renderer program and v5 request route. Add a video-specific request and published worker at the existing orchestration boundary. Route the bundled video fixture through Studio's Preview and the app gate without granting the worker access to app commands, desktop shortcuts or the profile.

Give the worker 2,400 ms to connect, validate the asset, decode and paint a first frame. Preload while muted and paused. Start playback after that paint and report visibility to the parent. After visibility the worker has up to the configured duration plus 600 ms to send a terminal event. The parent closes the owned job and allows up to 750 ms to confirm exit. The worst-case 13,750 ms leaves room for the 30-second app gate and 15-second target discovery under the existing 60-second Test launch wait.

The work manifest opts in with a `scene.video.json` asset. Metadata schema 1 declares an exact leaf MP4 asset name, `durationMilliseconds`, `fit` (`complete` or `fill`) and optional `sound` (default false). Verify the catalog, its declared assets and the local file before handing the path to the worker. Video wire version 1 has an 8 KiB framed message limit, a same-user pipe, and request ID correlation. The request carries the effective display mode, duration, fit and sound. The worker reports visible, completed, skipped, invalid media or failed. Timeouts and cleanup failures are classified by the owning process.

Use the window placement preference and monitor sizing already available from F18. Apply fit/fill inside that window. Build a separate WinForms worker using Windows Media Foundation and WIC. Package it alongside the native worker to share the pinned WinForms runtime. For muted AAC files, select only video in the Media Foundation Source Reader and never create an audio output. Use video timestamps to present decoded samples and hold the final frame if the video track ends before the container. Check playback performance and audio on 1080p fixtures on the workstation. A GPU surface is a follow-up if the measured goal changes.

Validate with a test-only packaged video fixture. F22 adds the import UI and F23 ships curated content. For release, record actual package evidence and regress both native works against 0.19.0.
