# Feature Specification — F11 设置与本地诊断

**Feature Branch** `codex/f11-settings-diagnostics`

**Created** 2026-11-03 · **Updated** 2026-11-06 · **Status** Complete

**Input** PRD V1.0 设置与恢复，TDD V1.0 §12，F02/F06/F10 已验证合同。

## User Scenarios & Testing

### User Story 1 — 修改并保存偏好 (P1)

用户通过 Studio 设置选择跟随系统、浅色或深色，并设置全局静音。应用重开后保留偏好。

**Independent Test** 使用隔离配置打开设置，变更、取消、保存并重开 Studio。

1. **AC-01** 三种主题在 Studio 各页面可识别，保存后立即生效，重开后保留。跟随系统对可读系统偏好生效，高对比度优先保证可读性。
2. **AC-02** 静音保存后在各次会话中显示一致。当前无声作品继续播放。取消和重复提交相同值保持配置字节。
3. **AC-03** 已有配置可读取，未知版本、写入失败或并发偏好更新有明确状态。失败时显示最新可读偏好，原有应用、绑定和其他数据完整。

### User Story 2 — 定位失败和查看本地记录 (P1)

用户可在诊断中定位最近一次启动或播放故障，并复制适合分享的摘要。

**Independent Test** 用隔离启动目标分别触发成功、绑定失败和渲染故障，查看诊断。

1. **AC-04** 查看 Studio、Launcher、MotionHost 与协议版本或缺失状态、当前渲染方式和可用系统动效偏好。能区分目标失败与动效降级。
2. **AC-05** 最近记录显示阶段、时间、结果和恢复提示。复制摘要需要明确操作，输出与本地记录不含用户路径、应用参数、标识原文、异常消息、窗口标题、画面或令牌。
3. **AC-06** 记录滚动保留，达到数量或大小限制时只保留有界数据。不可写、损坏或未知版本时，Launcher 与渲染清理照常完成，诊断显示不可用状态。

### User Story 3 — 从诊断进入安全恢复 (P2)

用户能查看所选应用的桌面入口健康情况，在缺失或过期时明确发起修复。

**Independent Test** 从 Studio 选择有入口的应用，模拟入口缺失、编辑和目录重定向，再查看并执行可用恢复动作。

1. **AC-07** 显示来自 F10 的状态，只有符合资格的缺失或待修复入口可修复。修复沿用 F10 的校验，冲突或不可用对象保留原样。
2. **AC-08** 无可选应用、报告为空、剪贴板不可用或日志目录不存在时提供清晰反馈。查看诊断和复制摘要不启动目标应用。

### Edge Cases

- 快速切换主题、系统偏好读取失败、高对比度、取消、配置并发写、异常配置和重开。
- 记录满、文件被占用、未知版本、输入故意包含机密字符串、日志故障和渲染故障同时出现。
- 所选应用在诊断打开后被移除，入口状态在修复期间改变，剪贴板忙。

## Requirements

- **FR-001** Studio 提供持久化主题偏好及即时更新，支持浅色、深色、跟随系统和高对比度可读性。
- **FR-002** 全局静音作为独立音频偏好保存。当前作品无音频，后续音频播放需要读取偏好；静音不改变动效或目标启动。
- **FR-003** 偏好保存事务只修改设置，检测并发偏好变化，兼容既有配置，失败不覆盖原始数据。
- **FR-004** 在启动与动效关键失败边界记录版本、阶段、时间、相关随机请求 ID、结果、降级原因和可用耗时。只允许预定义字段与结果，默认本机保存。
- **FR-005** 记录最多保留 128 条且占用不超过 64 KiB 的已提交记录数据。诊断故障不阻断启动或清理。未知或损坏记录保留原始内容并报告状态。
- **FR-006** 本地诊断界面显示组件与协议版本、运行能力、最近结果和受管入口健康。用户可打开日志目录和主动复制脱敏摘要。
- **FR-007** 恢复只调用 F10 已验证的修复合同。键盘可访问设置、诊断和恢复。普通用户可离线完成全部操作。

### Business Rules, Inputs & Outputs

- **Input** 用户明确选择的偏好、应用选择、组件状态和预定义诊断事件。
- **Output** 已提交的用户偏好、可读本地状态、有限记录与可复制摘要。
- **Rule** 每次启动可由随机请求 ID 关联。诊断不记录名称、路径或配置原文。组件不可用应如实报告。
- **Rule** 已有 GDI+ 矢量渲染沿用系统动画设置。设备探测只展示能可靠读取的能力。

### Key Entities

- **偏好** 主题及静音，保存在既有用户配置。
- **诊断记录** 版本、时间、请求身份、阶段、结果及受控兼容性字段。
- **恢复视图** 所选绑定、入口健康及显式修复意图。

## Success Criteria

- **SC-001** 真实 Windows Studio 中验证主题、静音持久化、取消和并发失败反馈，配置非偏好字段与备份有字节证据。
- **SC-002** 真实 Launcher 故障与原生降级可在诊断中区分，验证日志与复制文本均无注入的敏感字段，数量和字节上限通过自动化验证。
- **SC-003** 诊断读写失败时仍可验证单次目标调度和清理，F10 修复边界及 F08–F10 回归通过。

## Assumptions

- 目标 Windows 11 x64，依赖 F02、F06、F08、F09、F10。当前作品无音频，音频输出属于后续作品能力。
- 键盘流程和系统主题以实际桌面验证，罕见故障可用确定性注入测试。

## Clarifications

### Session 2026-11-06

- 主题和静音通过保存提交，取消保持原状态。并发偏好更新要求用户刷新后再保存。
- 可分享摘要不包含应用或作品标识，即使部分标识来自内置目录。记录只用于本地诊断。
- 恢复沿用所选应用的 F10 修复，安装、卸载和全量清理属于 F12。
