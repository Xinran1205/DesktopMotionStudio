# Playback / preview IPC v2

- Explicit protocol version2; profile2 and scene-manifest1 versions are independent. Reject unknown versions before interpreting playback. Existing v1 is not silently widened; old/new peer mismatch produces structured UnsupportedProtocol and native launch remains fail-open. Retain the 8KiB frame cap and strict enums/required fields/duplicate/unknown-member rejection.
- Start contains request identity, Mode=Launch|Preview, manifest identity/display mode, <=10s visible watchdog and optional immutable playback snapshot. Preview requires supported valid snapshot; lifecycle-only Launch remains diagnostic compatibility behavior. No appId/target/EXE/args/PID/HWND occurs in renderer payload.
- Shared definition/runtime version/frame evaluator/paint produce the same scene frames at the same elapsed time and motion preference. Launch accepts real target-ready Handoff immediately, preserving <=300ms close/fade. Preview completes the finite sequence and simulates a clearly labelled handoff without target authority.
- Ready → Start → Started → natural Completed is legal only in Preview. Launch finishes via Handoff/Shutdown. Skip/Stop/failure/EOF/watchdog are explicit terminal paths; natural completion is not TimedOut.
- Parent owns Started/Completion/Stop/Dispose. One generation-controlled preview slot; close old host before new Start. Every callback is request-bound; stale results only clean their own session. Startup connect/Ready each1s, Started750ms, duration<=8s, visible watchdog<=10s; Stop1s graceful+1s forced cleanup.
- Create the owned renderer directly in an unnamed KILL_ON_JOB_CLOSE job with STARTUPINFOEX/PROC_THREAD_ATTRIBUTE_JOB_LIST and no inherited job handle. Create-then-Assign (including suspended) is not sufficient. Creation/association failure returns failure without an orphan. Never put a target app or Studio into the job. Parent death, including during early creation or with hung host UI, closes ownership and terminates the renderer.
- Host revalidates snapshot and keeps reading Stop/EOF while playing. Reduced motion is queried read-only; lookup failure selects the conservative path. Stopwatch prevents accumulated Tick drift but does not handle a hung UI by itself: the live parent owns an independent non-UI deadline from Started and closes the job on timeout without waiting for Stop response. Verify parent alive + hung host + no user Stop yields TimedOut and cleanup within the hard bound.
- Isolated POC tests rendering only; production handshake/jobs/fail-open/actual target handoff/concurrency need their own integration and Windows evidence.
