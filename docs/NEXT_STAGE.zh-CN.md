# 下一阶段开发路线

- **基线**　0.15.0 · F15 已验收 · `6466123`
- **版本**　1.1 · 2026-11-08 · F13、F16 已交付为本机候选版

本阶段交付一套原创纯科技启动动效「零界」，以及一次 Studio 首页与产品图标的打磨。目标是让用户从首页选应用、选作品、预览和真实试启动，满意后自行创建桌面入口。现有绑定、Studio Pulse 和快捷方式继续可用。

## 开发顺序

| 顺序 | 开发内容 | 进入下一步的条件 |
| --- | --- | --- |
| 1 | **F13 视觉定稿与真机小样。** 用同一分镜做「点亮 → 对齐 → 交接」，对比居中大画幅和单屏全屏。先验证窗口早到、迟到、跳过，以及最短安全淡出。 | 本机看过两种构图，明确推荐尺寸和转场降级。确认动效可以短而完整，目标应用始终优先。 |
| 2 | **F13 将「零界」接入产品。** 上架原创封面，接通无目标应用的预览、真实测试启动与受管入口，保留旧作品可用。 | 两个不同的目标应用真实冷启动可用，热启动复用，Esc、故障、减弱动态和迟到退场有证据。独立审查、收敛后提交。 |
| 3 | **F16 首页与图标。** 以「零界」实际封面、播放状态和操作入口作为设计输入，重做常用流程的层级，定稿并接入 Windows 产品图标。 | 新用户可从空首页走到真实试启动。已有用户可访问设置、诊断和入口管理。键盘、主题、缩放和安装图标通过本机检查。独立审查、收敛后提交。 |
| 4 | **合并验收与候选包。** 跑一次完整回归并做一次本机安装包冒烟，更新使用指南，记录兼容性范围。 | 从 0.15.0 验证升级保留绑定和入口，安装版首页、图标、作品和真实启动可用。验证日志和候选包路径可追溯。 |

先做动效的小样，是为了尽早确定最难的窗口交接和构图。首页可以在小样时画一版低保真布局，产品界面实现等 F13 验收后再开始，直接使用真实的作品素材和状态。F13 可用现有界面独立交付。

## 已定方向与待评估项

- **已定**　首套采用原创纯科技风格，石墨黑、冰蓝细光和双层窗口轮廓。约 2 秒是分镜预算。真实应用就绪时可以提前交接。播放画面常态下只有作品，说明移到 Studio，键盘和指针仍可退出。
- **当前默认**　「零界」以作品推荐的居中大画幅为首选。全屏先进入同场对比小样。最终构图选择记入 F13 验收记录。用户可调尺寸和持久化偏好作为后续独立决策，等看过两版效果再排期。
- **交接取舍**　参考画面自然过渡到应用窗口的观感。先做适配范围更广的安全转场。目标窗口的大小与位置由目标应用决定。
- **后续作品**　F14 待本阶段验收后单独定主题、规格和分镜。二次元、搞笑、炫酷等风格逐套制作。

## 回归怎么简化

| 改动 | 日常验证 |
| --- | --- |
| 单套作品的分镜、封面或素材 | 验证包内资源。预览、跳过、一次真实冷启动，使用隔离测试配置。 |
| 首页布局、按钮或主题 | 跑 Studio 检查，在本机走一遍受影响路径，确认键盘和当前缩放。 |
| 共用渲染、交接、启动或存储 | 加跑相应自动化与受影响的本机路径。交接、崩溃和超时的观感以真实桌面为准。 |
| 安装或固定入口 | 验证受影响的安装生命周期。阶段发版时再跑完整回归和本机候选包冒烟。 |

本机验收沿用现有工作站与隔离测试数据。按阶段保存少量可复查的截图或短录屏、测试结果和未覆盖项。
