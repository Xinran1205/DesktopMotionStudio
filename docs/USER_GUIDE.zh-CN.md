# Desktop Motion Studio 使用指南

适用版本为 **0.21.0 本机候选版**，支持 Windows 11 x64。软件可以给你常用的应用加一个开场动效。你可以先预览作品，再实际打开应用试一次，满意后再创建桌面快捷方式。

## 五分钟上手

1. **安装并打开。** 运行 `DesktopMotionStudio.Setup.exe`，确认当前用户安装。从 Windows 开始菜单打开 **Desktop Motion Studio**。安装包已带运行时。
2. **添加一个常用应用。** 在「我的应用」点「添加应用」，从发现列表选择，或者手动选应用的 `.exe` 或本地 `.lnk`。首次体验可以选一个容易关闭的应用。
3. **绑定作品。** 选中应用，点「选择动效」，或打开「动效作品库」，选择 **零界** 并确认绑定。同一作品可以绑定给多个应用。已经有绑定时，使用「替换动效」。
4. **预览，再测试启动。** 「预览」只播放动效。「测试启动」会打开真实应用，并在首页显示结果。键盘可按 **Alt+T**。目标已运行时，软件会尝试切换到现有窗口。
5. **按需创建桌面入口。** 确定喜欢效果后，在「受管理桌面入口」点「创建入口」。以后可以从这个入口打开应用，Studio 可以关闭。你原来的应用入口仍可照常使用。

**零界**是首套原创纯科技作品，冰蓝光框约两秒完成点亮、对齐与收束，作品推荐区域为居中大画幅。开发作品 **Studio Pulse** 约五秒，原有绑定可以继续使用。冷启动会在动效退场后开始，随后是目标应用自己的加载时间。

## 现有功能

| 功能 | 怎么用 |
|---|---|
| 我的应用 | 添加、搜索、改显示名称、重新确认启动入口、移除配置。 |
| 动效作品库 | 查看作品封面和介绍，预览作品，为已有应用绑定或替换作品。 |
| 测试启动 | 从首页直接启动当前绑定的应用，查看冷启动、已有窗口和动效降级结果。 |
| 桌面入口 | 显式创建、修复或移除 Studio 管理的快捷方式。出现编辑或同名冲突时，原文件会保留。 |
| 停用动效 | 在应用详情点「停用动效」。已有受管入口仍可按原生方式启动应用。 |
| 设置 | 设置动效显示区域，切换简体中文或 English，选择主题或保存全局静音偏好。 |
| 本地诊断 | 查看最近启动、动效结果和桌面入口状态，可以主动复制摘要。 |

动效播放期间可按 **Esc**。预览时会关闭预览，真实启动时会跳过剩余动效并立即打开应用。播放「零界」时，移动指针或按 **Tab** 可看到退出按钮。如果渲染器不可用，软件仍会尝试正常打开目标应用。

在「设置 → 动效显示区域」选择 **作品推荐、居中小窗、居中大画幅、当前屏幕全屏**。保存后从下一次预览、测试启动或受管桌面入口生效。三种自选区域使用鼠标所在的显示器。目标应用的窗口仍由目标应用自己管理。

首次打开 Studio 时使用简体中文。打开「设置 → 界面语言」，选择 **English** 或 **简体中文**，保存并重新打开 Studio 即可切换。界面和内置作品名会随语言显示。你为应用填写的名称、应用路径和现有快捷方式名保留原样。

## 导入自己的 MP4

1. 打开「动效作品库」，点「导入 MP4」并选一个本地视频。
2. 检查通过后，设置作品名称、播放时长、画面适配和是否播放原声。时长默认取视频长度与 10 秒中的较短值，最短可设为 1 秒。画面默认完整显示，原声默认关闭，全局静音也适用于导入作品。
3. 点「预览作品」确认效果，再点「保存动效」。从「我的动效」选中作品，即可绑定给一个或多个应用。Studio 使用自己的本地副本，原文件可以移走。
4. 通过「编辑视频」调整选项。通过「移除视频」删除动效副本，已绑定的应用会恢复普通启动，现有桌面快捷方式仍可使用。

可导入最大 64 MB 的 H.264 MP4，使用 8-bit SDR、最高 30 fps，横屏最高 1920×1080，竖屏最高 1080×1920。音轨可使用 AAC 或留空。播放时会自动应用淡入淡出。

## 常用快捷键

| 快捷键 | 操作 |
|---|---|
| Alt+A | 添加应用 |
| Alt+L | 打开动效作品库 |
| Alt+P | 预览当前作品 |
| Alt+T | 在首页测试启动 |
| Alt+C / Alt+E / Alt+M | 创建、修复、移除当前桌面入口 |
| Alt+G / Alt+I | 设置、本地诊断 |
| Esc | 跳过当前播放，或取消当前弹窗 |

## 常见情况

- **测试启动按钮不可用。** 先选一个已绑定的应用，再检查启动入口是否可用。应用移动或更名后，可从详情重新确认入口。
- **应用打开了，动效没播放。** 应用已经运行时，可复用已有窗口。也可以查看动效是否停用，或在「本地诊断」查看具体结果。
- **找不到新建桌面入口。** 刷新详情，查看「受管理桌面入口」的状态。若原文件被移动或修改，先核对提示再处理。
- **升级提示应用正在使用。** 关闭 Studio，等本次启动和动效结束，再运行新版安装包。升级中途退出时，重跑同一版本安装包恢复。

## 升级、卸载和数据

运行新版 Setup 即可升级。卸载入口在 **Windows 设置 → 应用 → 已安装的应用 → Desktop Motion Studio**。卸载后，配置、备份和本地诊断保留在 `%LOCALAPPDATA%\DesktopMotionStudio`，重装可以继续使用。被编辑、移走或无法确认归属的快捷方式会保留，卸载结果会提示需要手工检查的项目。

0.21.0 是未签名的本机候选包。安装前可用同目录的 `setup.sha256` 核对文件。
