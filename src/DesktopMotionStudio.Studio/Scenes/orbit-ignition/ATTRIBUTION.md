# Orbit Ignition / 轨道点火

The fictional vehicle, hangar, stars, animated lights, exhaust, composition and timeline were authored for Desktop Motion Studio. The project distributes the rendered MP4 and cover with Studio. The cover is frame 82 of the authoring render. Both media files originate in the [authoring source](../../../../specs/024-first-mp4-work/authoring/Program.cs).

The picture uses original procedural geometry and contains no external illustrations, fonts, likenesses, characters, logos or audio. FFmpeg and libx264 are offline encoding tools in the authoring workflow. They are not bundled with Studio.
